# Utilisasi Kendaraan & GPS — Design Package

Paket berisi lima mockup revisi dan prompt untuk mengubah halaman Utilisasi pada dashboard baru.

Revisi terbaru: summary dipendekkan agar tabel harian naik; lebar konten tetap sejajar. Semua tombol Export dihapus. Acuan visual mengikuti halaman Analytics: Poppins, header filter existing, garis gradasi biru–hijau, dan header tabel biru dengan teks putih.

## Penggunaan

Buka PROMPT_IMPLEMENTASI.md, salin seluruh instruksinya ke coding assistant yang mengerjakan repository dashboard, lalu lampirkan kelima gambar di folder designs. Prompt tertulis dan komponen Analytics aktual menjadi acuan jika ada perbedaan kecil pada teks gambar.

Mockup merupakan referensi visual, bukan source code aplikasi. Semua angka pada gambar adalah data ilustrasi, bukan data operasional atau spesifikasi business logic baru. Moving dan Stopping menggunakan denominator yang sama dan total 100% saat data valid.
